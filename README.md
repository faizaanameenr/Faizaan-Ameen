# Faizaan Ameen R — Personal Portfolio

A responsive personal portfolio for **Vercel**, built with plain HTML, CSS, and JavaScript. No build step or framework required.

## Features
- Responsive layout and mobile navigation
- StudentOS project spotlight with links to the repository and releases
- Dark-violet visual system aligned with StudentOS
- Semantic HTML, reduced-motion support, descriptive metadata
- `Person` JSON-LD, Open Graph metadata, `robots.txt`, and `sitemap.xml`
- No contact form that falsely claims to send messages

## Deployment
This repository is connected to Vercel and deploys from the `main` branch.

Production URL: https://faizaan-ameen-r.vercel.app/

## SEO setup
1. Open Google Search Console and add the production URL.
2. Verify ownership using one of Google's offered methods.
3. Submit `https://faizaan-ameen-r.vercel.app/sitemap.xml`.
4. Inspect the homepage URL and request indexing after checking that it is publicly accessible.

Indexing and search appearance are controlled by Google and are not guaranteed immediately.

## Accuracy notes
The site avoids invented client names, awards, employment, audience counts, and performance metrics. The AI/automation and UI/UX sections are framed as areas of exploration and practice, not claimed commercial products. Review project status descriptions and links as work changes.
